Listas da API do Forever usadas pelo checar-combate.mjs, pelo rodar-central.mjs e pelo conferir-doc.mjs
(funcoes, eventos, templates, CVars, enums e a documentacao gerada da Blizzard). Ficam em api-forever\, fora do git.

Para baixar, nas versoes fixadas em api-forever.json e com o hash de cada arquivo conferido (a partir desta pasta):

    node baixar-api-forever.mjs

Fontes:
- GitHub Ketho/BlizzardInterfaceResources, branch "forever" (gerado do cliente). O api-forever.json fixa o
  commit d1ee5698 (build 1.60.1.70532, de 2026-10-21), o que estava em uso quando os checadores foram calibrados;
  em 2026-11-26 o branch ja estava no build 1.60.1.70938 (commit e230342a, de 2026-11-14).
- GitHub Ketho/wow-ui-source-forever, branch "forever": documentacao gerada da Blizzard (assinaturas, retornos e
  as marcas de valor secreto), commit bebcb6bf (build 1.60.1.70938, de 2026-11-13), em api-forever\doc\.

Para subir de versao: troque o commit no api-forever.json, rode "node baixar-api-forever.mjs --atualizar-hashes"
e rode as checagens (ferramentas\testar-tudo.ps1) antes de commitar.
